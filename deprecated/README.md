# Устаревшее: RRT* Планировщик Пути

> ⚠️ **УСТАРЕЛО** — Этот пакет заменён пакетом `astar_planner`.

## Статус

Пакет `rrt_star_planner` был перемещён сюда при переходе на планировщик A*.
Он **больше не используется** в активной системе.

## Замена

Планировщик A* (`astar_planner/`) заменяет этот пакет. См. основной
[README.md](../../README.md) и [docs/ASTAR_INTEGRATION.md](../../docs/ASTAR_INTEGRATION.md)
для подробностей.

## Почему он был заменён

| Критерий | RRT* | A* |
|-----------|------|-----|
| Оптимальность пути | ~105% от оптимального | Оптимальный (w=1.0) |
| Время планирования | 100–300 мс | 10–100 мс |
| Детерминизм | Недетерминированный | Детерминированный |
| Интеграция с картой стоимости | Своя проверка занятости | Прямая OccupancyGrid |
| Источник | Локальная реализация | Пакет `astar_planner` |

## Сохранено

Код сохранён здесь для справки и истории git. Чтобы восстановить его:

```bash
cp -r deprecated/rrt_star_planner ./
```

Затем обновите `costmap/launch/full_stack.launch.py` и `integrated_planning/launch/full_system.launch.py`,
чтобы использовать `rrt_star_planner` вместо `astar_planner`.
