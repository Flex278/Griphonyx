# Руководство по началу работы

Это руководство проведёт вас через первый запуск системы обнаружения препятствий.

## Проверка предварительных требований

Перед началом убедитесь, что у вас есть:
- [ ] ROS 2 Humble (или новее) установлен
- [ ] PX4 Autopilot склонирован и собран
- [ ] Gazebo Classic установлен
- [ ] Python 3.8+ с pip

## Пошаговая настройка

### 1. Проверка работы симуляции PX4

```bash
cd ~/PX4-Autopilot
make px4_sitl gazebo-classic
```

Вы должны увидеть БПЛА, появляющийся в Gazebo. Нажмите Ctrl+C для остановки.

### 2. Проверка конфигурации LiDAR

Запустите симуляцию PX4, затем в новом терминале:

```bash
ros2 topic list | grep cloud
```

Вы должны увидеть топик вида `/lidar/points` или подобный. Запомните точное имя.

```bash
ros2 topic info /lidar/points
```

Проверьте, что отображается: `Type: sensor_msgs/msg/PointCloud2`

### 3. Сборка пакета обнаружения препятствий

```bash
# Перейдите в ваше рабочее пространство ROS 2
cd ~/ros2_ws/src

# Клонируйте этот репозиторий
git clone <url-вашего-репозитория> griphonyx
cd griphonyx

# Установите зависимости Python
pip install -r requirements.txt

# Соберите пакет
cd ~/ros2_ws
colcon build --packages-select obstacle_detection
source install/setup.bash
```

### 4. Обновление конфигурации (при необходимости)

Если имя вашего топика LiDAR отличается, отредактируйте файл конфигурации:

```bash
nano ~/ros2_ws/src/griphonyx/obstacle_detection/config/params.yaml
```

Измените `lidar_topic` на имя вашего топика.

### 5. Запуск всей системы

Терминал 1 — Запуск PX4 + Gazebo:
```bash
cd ~/PX4-Autopilot
make px4_sitl gazebo-classic
```

Терминал 2 — Запуск детектора препятствий:
```bash
source ~/ros2_ws/install/setup.bash
ros2 launch obstacle_detection detection.launch.py
```

Терминал 3 — Мониторинг обнаружений:
```bash
ros2 topic echo /obstacle_detected
```

Терминал 4 — Мониторинг расстояний:
```bash
ros2 topic echo /obstacle_distance
```

### 6. Тестирование обнаружения

В Gazebo:
1. Вставьте простой объект (вкладка Insert → Box или Cylinder)
2. Разместите его перед БПЛА (в пределах 5 метров)
3. Наблюдайте за изменениями в Терминале 3

### 7. Визуализация в RViz2

```bash
rviz2
```

1. Установите Fixed Frame в `base_link` или ваш фрейм БПЛА
2. Add → PointCloud2 → Topic: `/lidar/points`
3. Убедитесь, что точки отображаются перед БПЛА

## Устранение неполадок

### Нет данных облака точек
- Проверьте, что LiDAR настроен в модели PX4
- Убедитесь, что имя топика соответствует конфигурации
- Проверьте `ros2 topic hz /lidar/points` для частоты обновления

### Нода падает при запуске
- Проверьте установку всех зависимостей: `pip install numpy`
- Проверьте, что рабочее пространство ROS 2 загружено: `source ~/ros2_ws/install/setup.bash`

### Ложные обнаружения
- Возможно, видна земная поверхность — настройте параметр `min_distance`
- Уменьшите `detection_height` для фильтрации низких точек

### Нет обнаружений при наличии препятствия
- Проверьте, что препятствие находится внутри бокса обнаружения (X > 0.3, |Y| < 2.0, |Z| < 1.5)
- Убедитесь, что `danger_distance` достаточно велик
- Используйте RViz2 для визуализации облака точек

## Дальнейшие шаги
