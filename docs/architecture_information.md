# Архитектурное решение: Кинодинамическое планирование пути RRT* для БПЛА с размахом крыльев 4.6 м

**Дата:** 22 февраля 2026  
**Статус:** Принято  
**Автор:** Команда автономности

## Контекст

Проект изначально рассматривал **Гибридную архитектуру (Глобальный граф + Локальный оптимизатор)** на основе комплексной оценки компромиссов. Однако после анализа характеристик БПЛА (размах крыльев 4.6 м, длина 4.4 м, высота 1.2 м) потребовалась критическая переоценка.

## Характеристики БПЛА

### Физические размеры
- **Размах крыльев:** 4.6 м
- **Длина:** 4.4 м, включая выступ винта
- **Высота:** ~1.2 м — зависит от конфигурации шасси
- **Полезная нагрузка:** короб 1.8×0.23×0.23 м

### Расчётные требования к просвету
- **Минимальная ширина коридора:** 10–12 м (размах крыльев + 2× запас безопасности)
- **Радиус раздутия препятствий:** 3 м (2× радиус крыла для безопасности)
- **Зоны конструктивного просвета:** Законцовки крыла, передние моторы/винты

## Сводка результатов сравнительного анализа

| Архитектура | Использование ресурсов | Оптимальность пути | Задержка планирования | Частота перепланирования |
|-------------|------------------------|-------------------|----------------------|-------------------------|
| **Гибридная (Глоб.+Лок.)** | 50–75% | 100–103% | 200–600 мс | 1.5–3.0 Гц |
| **RRT* кинодинамический** | 30–40% | ~105% | 100–300 мс | 1–2 Гц |
| **Реактивный локальный (DWA)** | 10–20% | 110–120% | <50 мс | 20–50 Гц |
| **Разреженный RRT*** | 30–45% | 102–110% | 100–300 мс | Н/Д |

## Решение

**Выбрано: RRT* с кинодинамическими ограничениями**

### Обоснование

#### 1. Эффективность использования ресурсов (Критично)
- **30–40% использования ЦП/памяти** против 50–75% для гибридного
- **Снижение на 40%** вычислительной нагрузки
- Оставляет запас для других критических систем (управление полётом, связь, полезная нагрузка)
- Тепловые и энергетические ограничения соблюдены

#### 2. Кинодинамическая пригодность (Существенно)
- **Учитывает ограничения радиуса поворота** (~20 м минимум для самолёта/СВВП)
- **Ограничения угла набора высоты** (максимум 20°)
- Генерирует **гладкие, выполнимые траектории** (без агрессивных зигзагов)
- Естественная интеграция с уставками позиции PX4

#### 3. Производительность планирования (Достаточно)
- **Горизонт планирования 100 м** подходит для полёта вперёд
- **Частота перепланирования 1–2 Гц** достаточна для динамики самолёта (не требует 20 Гц как мультиротор)
- **Задержка 100–300 мс** приемлема с учётом времени реакции аппарата
- Возможность досрочного завершения для чувствительных ко времени сценариев

#### 4. Обработка препятствий (Превосходно)
- **Запас безопасности 3 м** встроен в проверку столкновений
- Обрабатывает **большое раздутие препятствий** (критично для размаха 4.6 м)
- Естественное представление трёхмерного пространства препятствий
- Гарантии вероятностной полноты

#### 5. Сложность реализации (Управляема)
- Хорошо документированный алгоритм (Karaman & Frazzoli, 2011)
- Умеренная сложность по сравнению с гибридным подходом
- Чёткие рекомендации по настройке параметров
- Проверен в аналогичных аэрокосмических приложениях

### Принятые компромиссы

1. **Оптимальность пути:** ~105% против 100–103% для гибридного
   - **Приемлемо:** Увеличение длины пути на 5% незначительно по сравнению с выигрышем в лётной пригодности
   - Гладкие траектории снижают управляющее усилие и потребление энергии

2. **Частота перепланирования:** 1–2 Гц против 1.5–3.0 Гц для гибридного
   - **Приемлемо:** Самолёты имеют более медленную динамику, чем мультироторы
   - 1 Гц достаточно для обхода препятствий на типичных крейсерских скоростях (15–30 м/с)

## Рассмотренные и отклонённые альтернативы

### ❌ Реактивные локальные планировщики (DWA/VFH+)
**Почему отклонены:**
- Разработаны для высокоманёвренных мультироторов
- Горизонт планирования слишком короткий (<10 м) для аппарата с размахом 4.6 м
- Предполагают мгновенные изменения направления (невозможно для самолёта)
- Могут генерировать невыполнимые траектории с резкими поворотами

**Когда подходят:** Малые, манёвренные мультироторы в загромождённых внутренних средах

### ❌ Чисто гибридный (Глобальный граф + Локальный оптимизатор)
**Почему отклонён:**
- **Слишком высокое использование ресурсов:** 50–75% вызывает беспокойство для применения на БПЛА
- Добавленная сложность не даёт явного преимущества для данного случая
- Маржинальное улучшение оптимальности (100–103% против 105%) не оправдывает затрат
- Локальный оптимизатор может конфликтовать с кинодинамическими ограничениями

**Когда подходит:** Наземные роботы с обильными вычислениями, высокоструктурированные среды

### ❌ Коридорный A*
**Почему отклонён:**
- Требует предварительно вычисленной или известной структуры среды
- Не подходит для неизвестных/динамических сред
- Ограниченная трёхмерная манёвренность
- Лучше для навигации по путевым точкам с известными коридорами

**Когда подходит:** Наружная навигация в полуструктурированных пространствах (дороги, долины)

## Параметры реализации

### Обнаружение препятствий (обновлено для БПЛА с размахом 4.6 м)
```yaml
danger_distance: 80.0      # метры — время реакции для полёта вперёд
detection_width: 9.0       # метры — учитывает размах крыльев + запас
detection_height: 6.0      # метры — вертикальный просвет
min_distance: 2.0          # метры — игнорировать слишком близкие точки
obstacle_inflation: 3.0    # метры — конструктивный просвет
```

### Конфигурация планировщика RRT*
```yaml
max_iterations: 2000       # Бюджет планирования
step_size: 5.0            # метры — больше для крупного аппарата
goal_tolerance: 3.0       # метры — радиус принятия
search_radius: 15.0       # метры — радиус переподключения
planning_horizon: 100.0   # метры — дистанция взгляда вперёд
min_turn_radius: 20.0     # метры — кинодинамическое ограничение
obstacle_clearance: 3.0   # метры — запас безопасности
max_climb_angle: 20.0     # градусы — вертикальное ограничение
replan_rate: 1.0          # Гц — частота перепланирования самолёта
```

## Критерии валидации

Реализация RRT* будет считаться успешной, если:

1. **Использование ресурсов:** ЦП/Память остаются ниже 40% при номинальных операциях
2. **Качество пути:** Траектории выполнимы (соблюдают радиус поворота и угол набора высоты)
3. **Безопасность:** Все пути сохраняют зазор ≥3 м от препятствий
4. **Производительность:** Планирование завершается в пределах 300 мс для 95% случаев
5. **Надёжность:** Находит действительный путь, когда он существует (в пределах горизонта) в >90% сценариев

## Будущие соображения

### Краткосрочные улучшения
- Оптимизация сглаживания пути (кривые Безье, B-сплайны)
- Информированный RRT* (выборка с уклоном к цели)
- Многоразрешающее планирование (грубое, затем точное)

### Долгосрочные исследования
- Оптимизация траектории с учётом ветра
- Прогнозирование и избегание динамических препятствий
- Координация нескольких агентов (полёт в строю)
- Настройка функции стоимости на основе обучения
